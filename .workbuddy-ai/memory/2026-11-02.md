# 2026-11-02 · 双模式体验优化（出牌记录 / 提示 / AI 提速）

三条需求一起做，服务端 + 前端都动了。

## 1. 出牌区显示「这一轮所有出牌」

**问题**：出牌区只渲染 `roundCard` 最后一条，所以只看得见上一家出的牌。

**做法**：服务端新增 `roundLog`（`RoomLogEntry[]`，`pass?: boolean`），与 `round` 并行维护：
- `round` 仍是规则判定用的「有效出牌」，最后一条 = 当前要压的牌，**语义不变**
- `roundLog` 额外记录「不要」，给前端展示用
- 清空统一走 `clearRound(roomInfo)`（同时清 round / roundLog / notUseCardCount），
  原来 5 处 `roomInfo.round = []` 全部替换 —— 单独清会让列表和规则错位

前端 `buildRoundList(data)` 优先读 `roundLog`，老服务端没有就回退 `round`。
渲染改成 `.roundCardList` 横排多组 `.roundGroup`（昵称 + 牌 / 「不要」虚线胶囊），
牌宽按「总张数 + 组数」一起算（`roundTotalCards` / `roundGroupCount`）。
`lastRound` 改为「最后一个非 pass 条目」，压牌校验、「是否首个出牌」、回合提示都靠它。

## 2. 提示按钮

服务端新增 WS 消息 `hint`（`onHint`）：
- 斗地主：有上家牌走 `enumerateBeatCandidates`，王炸直接返回空；自由出牌走 `enumerateAll`
- 跑得快：`enumeratePdkBeats` / `enumeratePdkAll`，本房间第一局首出还要求带庄家牌
- 排序：非炸弹在前 → 主牌点数小的在前 → 张数少的在前；按牌 id 去重
- 按 `seq % list.length` 返回第 n 组，只回给发起人（`sendMesForPlay`），不改房间状态

前端底部加「提示」按钮，`hintRef = { key, seq }` 记录局面指纹
（`status|current|最后那手牌的 id`）：局面没变就 seq+1 轮换，变了从 0 开始。
收到 `{type:'hint'}` 直接 `setActiveCardId(cards)`；`total===0` 弹「没有能管上的牌」。

**为什么放服务端**：牌型识别 / 压牌只有一份（`utils/identify.ts` + `utils/pdk.ts`），
前端复刻必然和 AI、校验逻辑漂移 —— 这是跑得快那轮就定下的原则。

## 3. AI 出牌提速

原来 `1500 + random*1500`（1.5~3s）一刀切。改成按动作分档（`AI_THINK_MS`）：

| 动作 | 时长 |
|---|---|
| 叫地主 / 不叫 | 450~700ms |
| 出牌 | 650~1000ms |
| 不要 | 320~500ms |
| 掉线托管 | 再 ×0.6 |

**关键点**：决策逻辑一行没改。`scheduleAITurn` 里先空算一次决策只为了拿动作类型，
真正执行时在定时器内用**最新状态重算**，避免用过期决策（`computeAIDecision` 抽成纯函数）。
另外补了状态守卫：`status` 不在 play/useCard/selectLandlord 就直接放弃。

效果：跑得快整局从 ~17s 降到 ~10s，斗地主整局 ~22s。

## 4. 又一个 `left: 50%` 的坑

`.roundCardList` 也是绝对定位 + `left: 50%`，`width: auto` 时可用宽度只有一半，
320 屏三组牌被迫折成三行。加 `width: max-content` 修好（和 `.prepare` 同一个坑，已写进 CODE_WIKI §14）。

  和连点提示的合法性（牌都在手里 + 确实能压上 + 服务端接受这手牌）

  出牌区组数、是否溢出、提示选中张数都对

**测试脚本踩的坑**：用 `busy` 布尔量控制「每个局面只动作一次」，
斗地主叫完地主后局面直接变成「轮到我出牌」，新帧到达时 busy 还是 true → 脚本把自己锁死。
改成局面指纹后又踩了第二个坑：指纹里用 `round.length` 当「这一轮打到第几手」，
但一轮打完会清空、下一轮又攒到同样手数，指纹和上一轮撞上 → 同样锁死（斗地主 180s 超时）。
最终指纹带上「最后出的那手牌」本身：`status|current|最后那手|我的剩牌数`。
连跑两次分别 333 / 473 项全过。
